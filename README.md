My first Unity project — a sandbox for experimenting with game mechanics, physics, and rendering. It became the foundation for three completed games.

🎮 Games Built on This Project
This project was the starting point for:

Save the Village — A survival strategy with economic systems. Defend your village, manage resources, and grow your settlement.
🔗 SaveTheVillage branch

Wild Ball — A physics arcade with realistic ball simulation, textures, and materials.
🔗 Textures&Materials branch

The Clay — A 2D platformer with a dialogue system and enemy AI.
🔗 Platformer.PartIV branch
