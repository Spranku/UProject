## 🎮 Gameplay

As the nameless hero, navigate through grim caves filled with deadly traps and an ancient evil. Fight humanoid entities — creatures of shadow, relentless and merciless — at every turn.

---

## 🛠️ Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Art Style:** 2D pixel art
